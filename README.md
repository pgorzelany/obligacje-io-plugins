# obligacje.io distribution packages

This repository contains only the public static integration packages for obligacje.io. The backend repository remains private.

- [OpenAI portable package](./openai/README.md)
- [Claude plugin package](./claude/README.md)

OpenAI package version **0.1.4** uses display name **ObligacjeIO**, English base listing text and a bundled **pl-PL** translation. Claude package version **0.1.0** remains unchanged; Claude upload, testing and publication remain deferred. Production acceptance and directory review/publication are pending. No live listing is claimed. Hosted OAuth in ChatGPT and claude.ai is the launch target; Code/Codex loopback OAuth is unsupported and Cowork is unverified.
