# obligacje.io distribution packages

This repository contains only the public static integration packages for obligacje.io. The backend repository remains private.

- [OpenAI portable package](./openai/README.md)
- [Claude plugin package](./claude/README.md)

Version 0.1.7: static distribution package. Catalog coverage and capabilities are established by current tool results. For connection requirements and current client guidance, see [the setup guide](https://www.obligacje.io/en/integrations). Package export does not verify hosted behavior, review or publication.
